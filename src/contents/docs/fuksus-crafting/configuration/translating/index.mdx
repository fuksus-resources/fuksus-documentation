---
title: Translating
description: Quickly translate the resource to any language you want!
---

<Note type="note" title="Info">
  We currently support only English and Lithuanian as default languages.
  If you want to contribute to the resource translations contact us on Discord.
</Note>

You can find all the translations at `fuksus-crafting/locales/` folder.

Translation codes starting in `ui_` are used in the User interface.
